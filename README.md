# Bliźniak 155 m² – ul. Sprawna, Warszawa Białołęka

Statyczna strona ogłoszenia sprzedaży domu.

## Publikacja (GitHub Pages)
Settings → Pages → Source: *Deploy from a branch* → Branch: `main`, folder `/ (root)` → Save.
Po chwili strona będzie dostępna pod adresem `https://piotrkomosinski.github.io/sprzedazsprawna/`.

## Struktura
- `index.html` – treść ogłoszenia
- `style.css`, `script.js` – wygląd, galeria (lightbox), mapa
- `img/` – zdjęcia (2000 px) i miniatury (`img/thumb/`), bez metadanych EXIF/GPS
- `plan-domu.pdf` – plan do pobrania
